Google sign-in setup

Google sign-in needs an OAuth Client ID for wherever this app is hosted (one-time, free):

  1. Open Google Cloud → Credentials and create an OAuth client ID of type Web application.
  2. Under Authorized JavaScript origins add .
  3. Enable the Google Drive API for the project (used to sync your sessions).
  4. Paste the Client ID below, or put it in hub/config.js.

Subscriptions like Claude Pro, Gemini Advanced or SuperGrok can't be used by other apps. AI Hub talks to each provider with your own API key, sent straight from your browser to that provider.
